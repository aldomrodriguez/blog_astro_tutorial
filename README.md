# Blog con Astro

Blog de práctica hecho siguiendo el tutorial oficial de [Astro](https://docs.astro.build/es/tutorial/0-introduction/).

## Qué incluye

- Publicaciones en Markdown con un layout propio.
- Página de etiquetas generada a partir de las publicaciones.
- Página "Sobre mí" y listado del blog.
- Menú de hamburguesa para celular.

## Cómo correrlo

```sh
pnpm install
pnpm dev
```

| Comando        | Qué hace                                  |
| :------------- | :---------------------------------------- |
| `pnpm dev`     | Levanta el servidor local en `localhost:4321` |
| `pnpm build`   | Genera el sitio en `./dist/`              |
| `pnpm preview` | Sirve el build para revisarlo             |
